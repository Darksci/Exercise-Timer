# Exercise Timer PWA

This is an installable Progressive Web App.

## iPhone installation

1. Host these files on an HTTPS website (GitHub Pages is a good free option).
2. Open the website in Safari on your iPhone.
3. Tap Share.
4. Choose "Add to Home Screen".
5. Tap Add.

The installed app uses standalone mode, has its own icon, and caches the app shell for offline use.

Note: iOS requires a secure HTTPS origin for service workers/PWA installation. `file://` local HTML files cannot provide the full PWA experience.
